# NIFTY 50 Stock Market Analysis Dashboard

## Overview

A Python-based financial market analysis project that uses
NIFTY 50 historical data to study price trends, moving averages,
daily returns, and market volatility.

## Technologies Used

- Python
- yFinance
- Pandas
- NumPy
- Matplotlib

## Features

- Downloads NIFTY 50 historical market data
- Calculates 20-day moving average
- Calculates 50-day moving average
- Calculates daily returns
- Calculates rolling volatility
- Visualizes price trends
- Visualizes market volatility
- Exports processed data to CSV

## How to Run

1. Install Python
2. Install required libraries
3. Run stock_analysis.py

## Key Learning

This project demonstrates the use of Python for financial
data collection, data processing, statistical analysis and
financial visualization.
